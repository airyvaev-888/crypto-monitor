# Crypto Monitor

Бот для мониторинга ликвидных криптовалют на топовых биржах (Binance, KuCoin, Bybit, Gate.io, MEXC) с уведомлениями в ntfy.

## Функционал
- Мониторинг топ-20 монет по объёму с каждой биржи.
- Расчёт технических индикаторов (RSI, MACD, Bollinger Bands, Stochastic, ADX, EMA).
- Генерация торговых сигналов (BUY/SELL/HOLD).
- Поиск дивергенций.
- Отправка уведомлений в ntfy при смене сигнала.
- Бэктестинг стратегии на исторических данных.
- Дополнительный анализ через CoinMarketCap.

## Установка
1. Клонируй репозиторий.
2. Создай файл `.env` на основе `.env.example`.
3. Заполни API-ключи бирж и `NTFY_URL`.
4. Установи зависимости:
   ```bash
   pip install -r requirements.txt
